# E-Commerce Revenue & Pricing Strategy Analysis

## Project Overview
This project analyzes an e-commerce dataset to uncover insights into revenue generation, category performance, and customer payment preferences. The data was modeled in PostgreSQL and visualized in an interactive Power BI dashboard.

## Tools Used
* **PostgreSQL:** Data staging, type casting, and exploratory data analysis.
* **Power BI:** Data visualization, interactive filtering, and dashboard design.

## Key Insights
* **Total Revenue:** Tracked ₹757.28K in gross revenue across 3,660 individual transactions.
* **Top Performers:** 'Clothing' emerged as the highest revenue-generating category (₹115K), closely followed by 'Books' (₹111K). 
* **Payment Distribution:** Customer payment methods were highly balanced, with a near-perfect ~20% split across Credit Card, UPI, Debit Card, Net Banking, and Cash on Delivery.

## Files in this Repository
* `queries.sql`: The SQL scripts used to build the database schema and query the insights.
* `Ecommerce_Project.pbix`: The interactive Power BI dashboard file.
* `Dashboard_Preview.pdf`: A static PDF export of the final dashboard.
* `dataset.csv`: The raw data used for this analysis.
